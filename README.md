# Portafolio de Programación

Repositorio personal donde recopilo los trabajos, ejercicios y proyectos desarrollados a lo largo de mi formación en programación. Sirve como registro de aprendizaje y como portafolio para mostrar el progreso en distintos lenguajes y herramientas.

## 📂 Estructura del repositorio

| Carpeta | Contenido |
|---|---|
| [`JAVA`](./JAVA) | Fundamentos básicos del lenguaje: JOptionPane, variables, vectores y matrices, además de Programación Orientada a Objetos (POO). |
| [`PYTHON`](./PYTHON) | Principios básicos de programación, fundamentos de POO y ejercicios de integración con bases de datos SQL. |
| [`SQL`](./SQL) | Archivos de prueba relacionados con bases de datos. |
| [`HTML`](./HTML) | Pruebas de páginas web. |
| [`PSEINT`](./PSEINT) | Ejercicios de inicio a la programación (pseudocódigo). |
| [`TRABAJOS`](./TRABAJOS) | Trabajos, talleres y entregables asignados durante el curso. |

## 🎯 Propósito

Este repositorio tiene como objetivo:

- Centralizar el material de práctica y los trabajos realizados durante la formación técnica/tecnológica en programación.
- Servir como referencia personal para repasar conceptos ya vistos en clase.
- Documentar el progreso y la evolución en el aprendizaje de distintos lenguajes de programación.

## 🛠️ Tecnologías y herramientas

- **Java** — JOptionPane, variables, vectores, matrices y Programación Orientada a Objetos.
- **Python** — Fundamentos de programación, POO y conexión con bases de datos SQL.
- **SQL** — Archivos de prueba de bases de datos.
- **HTML** — Pruebas de páginas web.
- **PSeInt** — Ejercicios de inicio a la programación mediante pseudocódigo.

## 📌 Estado

Repositorio en construcción activa. Se irá actualizando conforme avance el curso con nuevos ejercicios, talleres y proyectos.
