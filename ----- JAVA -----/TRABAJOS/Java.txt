----- variables -----

las variables de java son estaticas, osea que lo que contien no puede cambiar ( si es float se queda en float)

--- variables enteros: ---

- byte: 1byte ( -128 to 127)
- short: 2bytes ( -32,768 to 32,767)
- int: 4bytes ( -2,147,483,648 to 2,147,483,647)
- long: 8bytes ( -9,223,372,036,854,775,808 to 9,223,372,036,854,775,807)


para float se debe de colocar la letra F despues del numero
